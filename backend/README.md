# FoodLens AI backend

Необов’язковий FastAPI-сервер для аналізу фото страв. Приймає зображення від iOS-застосунку, надсилає його зовнішній моделі й повертає структурований результат українською мовою.

## Запуск

Потрібні Python 3.10+ та облікові дані зовнішнього API.

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export OPENAI_API_KEY="YOUR_API_KEY"
uvicorn main:app --host 0.0.0.0 --port 8000
```

`OPENAI_API_KEY` — обов’язкова змінна. `OPENAI_MODEL` — необов’язкове перевизначення моделі; поточне значення за замовчуванням записане у `main.py` та `.env.example`. Доступність вибраної моделі залежить від облікового запису постачальника.

Файл `.env.example` є прикладом. Поточний код не завантажує `.env` автоматично: передайте змінні процесу через shell або конфігурацію середовища запуску.

## Підключення iPhone

У FoodLens відкрийте «Сьогодні» → налаштування → «AI-сервер» і вкажіть базову адресу без `/analyze`, наприклад `https://foodlens.example.com`.

Для локальної розробки телефон і Mac мають бачити один одного в мережі. `localhost` на телефоні означає сам телефон. Приклад локальної адреси: `http://192.168.1.20:8000`. Поточний `Info.plist` не містить винятків App Transport Security: незахищений HTTP може блокуватися iOS. Використовуйте HTTPS або окремо налаштуйте мережевий доступ для локальної розробки.

## HTTP API

### GET /health

Повертає `{"status":"ok"}`. Це перевірка роботи процесу, яка не перевіряє API-ключ або доступність моделі.

```bash
curl http://127.0.0.1:8000/health
```

### POST /analyze

Тіло запиту — JSON із полем `image_base64`, що містить Base64 JPEG без префікса data URL.

| Поле відповіді | Значення |
| --- | --- |
| `dish` | Назва страви |
| `estimatedGrams` | Орієнтовна вага порції, г |
| `caloriesPer100g` | Калорійність на 100 г |
| `protein`, `carbs`, `fat`, `fiber` | Показники всієї порції, г |
| `confidence` | Заявлена впевненість у межах 0–1 |
| `ingredients` | Список оцінених компонентів |

Кожен компонент містить `id`, `name`, `grams`, `calories`, `protein`, `carbs`, `fat`, `fiber`. Калорії компонента стосуються його зазначеної порції. Сервер замінює ідентифікатори компонентів на UUID.

Автоматична документація FastAPI доступна на `/docs`. Відповідь моделі запитується за JSON Schema, визначеною у `main.py`.

## Помилки та обмеження

- Відсутній ключ: HTTP 503.
- Невідповідне тіло запиту: стандартна валідація FastAPI.
- Помилка зовнішнього API: передається його HTTP-код та текст відповіді.
- Немає структурованого тексту у відповіді: HTTP 502.
- Таймаут зовнішнього HTTP-клієнта: 60 секунд.
- Мережеві помилки, некоректний JSON моделі та деякі неочікувані відповіді не мають окремого обробника й можуть завершуватися HTTP 500.

Це сервер для розробки. Поточна реалізація не містить автентифікації клієнтів, квот, обмеження розміру зображень або rate limiting. Перед відкриттям доступу в інтернет ці механізми слід налаштувати на сервері або reverse proxy. HTTPS забезпечує середовище розгортання.

Зображення передається зовнішньому API. Власної бази даних або збереження фото на диск код сервера не реалізує. API-ключ не додавайте до iOS-коду чи репозиторію.
